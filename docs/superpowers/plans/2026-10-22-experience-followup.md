# 体验修复设计与执行记录

用户已授权针对上一轮体验问题继续修改调试。沿用现有五步骤结构，不引入账号系统或云端个人数据存储。

- 本机版本化草稿，七天有效期、清除入口和异常提示；保存个人信息、结果、报告、步骤。恢复时验证版本、时间及基础字段，并按已有结果限制可访问步骤。
- 当前标签页模型偏好通过请求头传递，服务端 ContextVar 隔离；兼容未提供请求头的默认环境配置，线程池继承请求上下文。
- 现有报告接口保持 JSON 兼容，可选 NDJSON 流反馈章节完成和最终报告。只重试请求体明确指定的合法章节，前端合并指定章节并保留编辑。
- 请求结果以发起时资料版本检查，避免清除或修改后旧结果覆盖当前状态。
- 先复现模型全局污染、重试七章、刷新丢失、清除后结果回写，再实施修复；运行后台与浏览器回归、生产构建和真实单章模型验收。

保留限制：草稿不跨设备；模型正文事实和外部资源有效性仍需核实；线上恢复单独处理。
